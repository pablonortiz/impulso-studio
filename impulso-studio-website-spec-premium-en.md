**Primary goal:** Lead generation via WhatsApp (click-to-chat)

## 1) Tech Stack (Mandatory)

- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Animation: Framer Motion
- Hosting: Vercel
- SEO: Required (metadata, OG, sitemap, semantics)

### Constraints
- Do NOT mention technologies in user-facing copy
- Use plural institutional voice (“Creamos”, “Diseñamos”, “Impulsamos”)
- Target audience is non-technical
- Spanish copy only in UI text

### PROJECTS (ANONYMIZED CASES)

#### Gestión de vehículos y documentación
**Problema:** Información dispersa y difícil de mantener actualizada.  
**Solución:** Sistema centralizado para vehículos, responsables y documentos.  
**Resultados:**  
- Control total desde un solo lugar  
- Documentación siempre disponible  
- Menos errores administrativos  

---

#### Catalogador de extractos bancarios
**Problema:** Revisión manual de extractos, lenta y propensa a errores.  
**Solución:** Sistema que identifica, clasifica y estandariza movimientos.  
**Resultados:**  
- Procesos más rápidos  
- Información lista para exportar  
- Menos intervención manual  

---

#### Web inmobiliaria con panel de gestión
**Problema:** Publicaciones desordenadas y consultas difíciles de gestionar.  
**Solución:** Web con catálogo, formularios y panel administrativo.  
**Resultados:**  
- Mejor presentación del negocio  
- Consultas centralizadas  
- Gestión simple de propiedades  

---

#### Sistema de gestión para metalúrgica
**Problema:** Datos históricos dispersos y difícil análisis del negocio.  
**Solución:** Plataforma unificada para trabajos, gastos y reportes.  
**Resultados:**  
- +80.000 registros organizados  
- Visión clara de la operación  
- Reportes por período y estado  

---

#### Gestión de stock de perfumes
**Problema:** Control manual del stock y comunicación poco clara con clientes.  
**Solución:** App para marcas, productos y stock exportable.  
**Resultados:**  
- Stock siempre actualizado  
- Listados claros para clientes  
- Mejor organización del catálogo
